Entire object isolated centered with safe margins on genuinely transparent alpha background, square image. No floor, no environment, no text, no letters, no UI, no logo, no person, no watermark, no shadow plate. Designed to sit as a small premium sculptural accent on a white website. The red and chrome material language must match a chrome gyroscope with a red core.
