## 2. Tempel README

Buka `README.md` pada repository tersebut, klik Edit, lalu ganti isinya dengan **isi mentah** file `README.md` dari paket ini. Gunakan tombol salin pada tampilan kode atau buka file dengan Notepad/VS Code dan salin seluruh isinya.

Jangan ikut menyalin pagar code block seperti ```markdown. Jangan menambahkan backslash sebelum tag HTML. Contoh yang benar: `<img src="..." />`, bukan `\<img src="..." />`. Atribut `src` berisi URL langsung, bukan `[URL](URL)`.

Pilih Preview untuk memeriksa hasil, lalu Commit changes. Repository harus tetap public dan README berada di root agar muncul di profil.

```text

```
